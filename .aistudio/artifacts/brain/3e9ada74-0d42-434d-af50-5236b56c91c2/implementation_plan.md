## 2. 已交付功能里程碑回顾 (Delivered Milestones)

| 阶段 | 交付核心功能 | 解决痛点与用户价值 | 状态 |
| :--- | :--- | :--- | :---: |
| **M1: 多媒体手帐编辑** | 图片滤镜/文本框涂鸦批注 (`ImageEditorModal`)、烹饪视频封面与步骤视频播放 (`VideoPlayer`) | 支持图文并茂+视频记录，解决静态文字菜谱无法展示关键火候与油温的痛点 | ✅ 已上线 |
| **M2: 食味广场与社交互动** | 广场社区浏览 (`CulinarySquareView`)、菜谱一键克隆收录 (`Fork & Clone`)、厨友点赞评价留言 (`SquareReviewModal`) | 允许用户分享拿手硬菜、互相汲取烹饪灵感，形成有温度的美食圈子 | ✅ 已上线 |
| **M3: 下厨制作与打勾清单** | 制作执行模块 (`CookingExecutionView`)，支持食材备料打勾、步骤火候跟踪、厨房多时钟并行倒计时 | 告别厨房手忙脚乱，下厨时单手操作逐步确认，彻底消除漏放调料的情况 | ✅ 已上线 |
| **M4: 氛围与个性化主题** | 5 套手帐主题 (`ThemeSwitcher`)：复古手帐、温暖亚麻、深夜食堂暗黑、抹茶清心、樱花甜点 | 满足不同用户的审美偏好，夜晚下厨支持暗黑模式保护视力 | ✅ 已上线 |
| **M5: 模糊联想与拼音搜索** | 智能联想搜索条 (`FuzzySearchBar`)，支持菜名模糊匹配、拼音首字母/全拼联想、食材与标签反查 | 即使记不清菜谱确切全名，也能通过“xhs(西红柿)”或食材一键联想出对应菜品 | ✅ 已上线 |
| **M6: 双级分类与标签体系** | 自定义主分类与二级细分管理 (`CategoryManagerModal`)、自定义风味标签与天气印记 | 满足中式、烘焙、地方菜系等多层分类需求，用户可自由扩充私房分类体系 | ✅ 已上线 |
| **M7: 语音实时转写录写** | Gemini 驱动的语音转文字服务 (`/api/transcribe`) + 录音按钮 (`VoiceTranscriptionButton`) | 下厨备料时双手带水或油污，只需轻点录音即可通过语音快速口述步骤与心得 | ✅ 已上线 |
| **M8: 智能购物清单与缺货预约** | 勾选食材一键转换购物清单 (`ShoppingListModal`)，按蔬菜/肉类/调味分类，配置购买偏好与缺货预约提醒 | 制作打勾后无缝衔接采买，支持记住用户的品牌、规格偏好及缺货闹钟 | ✅ 已上线 |
| **M9: 精美 A4 手帐 PDF 导出与打印** | 专用手帐导出窗口 (`RecipePDFExportModal`) + `@media print` 打印样式优化，支持全彩手帐/省墨黑白/高清长图 | 方便打印贴在厨房冰箱上、装订成实体私房家传菜谱、或离线保存为矢量 PDF | ✅ 已上线 |
| **M10: 饮食健康与热量智能测算** | 营养换算引擎 (`nutritionCalculator.ts`) + 菜谱编辑器热量字段 + 详情页健康卡片与食材热量拆解 | 自动根据食材用量换算整锅与每份热量，提供低卡/均衡/能量健康评级 | ✅ 已上线 |

## 3. 下一阶段核心研发任务 (Next Horizons & Roadmap)

### 阶段 11：食材购物直达与生鲜电商平台联动 (E-Commerce Purchase Deep Links)
- **目标**：在制作模块和购物清单中，为食材提供可点击的**超链接或一键购买入口**，直达主流生鲜与电商平台。
- **规划实现**：
  1. 为清单中的每项食材配置电商平台直达链接（盒马、山姆会员商店、京东到家、美团买菜、拼多多生鲜）；
  2. 支持用户设置默认首选生鲜平台；
  3. 支持将整份清单一键生成“一键复制搜购文本”，方便快速粘贴至买菜 App 搜索栏。

### 阶段 12：深度营养素宏量分析与膳食平衡仪表盘 (Macronutrients & Diet Balance)
- **目标**：在热量测算基础上，进一步提供**蛋白质 (Protein)、碳水化合物 (Carbs)、脂肪 (Fat) 三大宏量营养素**的分析图表。
- **规划实现**：
  1. 营养成分环形比例图（P:C:F 比例分析），直观展示高蛋白、生酮低碳或减脂高纤配比；
  2. 钠含量（盐分控制）及控糖提示，助力三高与健身人群精细化饮食管理；
  3. 每日/每周下厨摄入营养热量聚合报表（结合打卡下厨日历）。

### 阶段 13：家庭协同与共享手帐本 (Family Shared Scrapbook)
- **目标**：允许多个家庭成员或情侣共同管理一个私房手帐空间。
- **规划实现**：
  1. 通过家庭邀请码邀请成员加入“家庭厨房”；
  2. 协同编辑家传秘方、共享同一份采购清单；
  3. 菜谱下方支持标注“今天谁掌勺”与家庭成员口味评分。

### 阶段 14：语音交互小助手与免触控厨房模式 (Hands-free Kitchen Voice Assistant)
- **目标**：戴上耳机或手机立在台面上，无需触屏即可完成做菜全过程。
- **规划实现**：
  1. 语音播报：“开始第 2 步”、“播报调料用量”；
  2. 语音控制计时器启动、暂停与查询剩余时间；
  3. “下一步 / 重新听一遍”免唤醒词语音操控。

## 4. 技术栈与工程实践规范

- **前端架构**：React 19 + TypeScript + Vite + Tailwind CSS
- **后端服务**：Node.js Express + TSX (`server.ts`)
- **智能计算**：
  - 音频流与实时语音转写：`@google/genai` (Gemini 3.5 Transcribe API)
  - 食物营养计算引擎：基于《中国食物成分表》可食部分标准换算引擎
- **离线与数据韧性**：PWA Service Worker + 本地缓存与云端同步双层架构
- **设计准则**：
  - 遵循 Zero-Pill 极简拟真排版，手帐和纸胶带、牛皮纸纹理与火漆印章质感；
  - 打印媒体查询（`@media print`）严格隔离无关页面元素，确保单页与双页打印分页无截断。
